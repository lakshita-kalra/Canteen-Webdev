🍽️ Canteen Management System

A Full-Stack Web Application that automates canteen operations such as menu management, order processing, and billing.
This project provides an efficient, paperless, and user-friendly solution for managing canteen services in colleges and offices.

🔗 Live Demo: https://magnificent-rolypoly-743520.netlify.app/

📖 About the Project

The Canteen Management System is designed to streamline the daily canteen operations by automating the process of taking orders, managing menus, handling billing, and maintaining stock records.
It ensures faster service, improved accuracy, and real-time updates for both customers and staff.

The system offers separate dashboards for:

🧑‍🎓 Customers – View menu, place orders, and make payments.

👨‍🍳 Staff/Admin – Manage orders, update menus, and track inventory.

✨ Features

✅ User Authentication – Secure login for staff and customers.
✅ Dynamic Menu Management – Add, edit, or delete menu items in real time.
✅ Order Management System – Customers can place orders; staff can view and update them.
✅ Billing System – Automatic total generation for every order.
✅ Database Integration – Stores all data (users, menu, orders) on the backend.
✅ Responsive UI – Fully optimized for both desktop and mobile screens.
✅ Real-Time Updates – Menu and orders refresh dynamically through backend API calls.

💻 Installation

If you want to run the project locally:

1. Clone the repository
git clone https://github.com/yourusername/canteen-management-system.git
cd canteen-management-system

2. Install dependencies (for backend)
cd backend
npm install

3. Run the backend server
node server.js

4. Open frontend

You can open index.html in your browser or run it using a local server (like Live Server in VS Code).

🚀 Usage

Login as Customer or Staff.

Customers can browse menu items and place orders.

Orders are sent to the backend for processing.

Staff can view and update order status.

Bills are generated automatically and stored.
